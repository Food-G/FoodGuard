6. 찾아서 고친 문제 4건
----------------------------------------------------------------
  [1] 코파일럿이 진행 중 발주를 0건으로 봄
      원인: 발주 675건 중 오래된 100건만 전달 (진행 중인 최신 발주가 잘림)
      수정: 진행 중 → 최신순으로 정렬, 상태별 건수를 항상 함께 전달  (fgagent/runtime/tools.py)
      결과: 정답 0/5 → 5/5

  [2] 코파일럿이 어제 매출·메뉴별 판매를 답하지 못함
      원인: CLI 모드에서는 도구를 못 쓰고, 미리 넘기는 데이터에 일별·메뉴별 판매가 없음
      수정: 최근 14일 일별 매출·수량과 7일 메뉴별 판매량 요약을 함께 전달  (fgagent/copilot.py)
      결과: 두 문항 모두 정답 0/5 → 5/5

  [3] 발주 참모 LLM이 정체 발주를 엉뚱한 식자재(마늘·참기름)에 연결
      원인: 정체 발주 경고 문구에 어떤 식자재인지가 빠져 있어 LLM이 추측
      수정: 경고에 "#450585 간장"처럼 발주 번호와 식자재 이름을 넣음  (fgcli/planner.py)
      결과: 잘못 연결 3/5 → 0/5 (수정 후 4회는 간장으로 정확히 설명)

  [4] 폐기 예측이 "평균값 추정이라 참고용"으로 안내됨
      원인: 예측이 내일부터라 오늘 하루만 평균으로 채워도 근거를 전부 fallback_avg 로 표시
      수정: 일부만 평균이면 mixed 로 표시 + 경고, 프롬프트 설명 보강
            (WastePredictionService.java, fgagent/waste_guard.md)
      결과: 오해를 부르는 안내 5/5 → 0/5

  테스트: 새 테스트 4개 포함 Python 183개 · Java 114개 모두 통과
  커밋: 아직 하지 않음
