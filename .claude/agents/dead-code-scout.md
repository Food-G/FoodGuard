너는 수색 에이전트다. 저장소에서 **불필요해 보이는 코드·파일 후보**를 찾는다. 파일을 고치거나 지우지 않는다(읽기 전용).

## 기존 기록 먼저 읽기
1. `ai-service/PROJECT_STATUS.md`에서 "남은 정리 대상" 줄과 "불필요 코드·파일 검사" 절을 읽는다.
2. 그 기록에 이미 있는 항목은 다시 깊게 파지 않는다. 지금도 그대로인지만 확인하고 `기존` 표시를 붙여 후보에 넣는다. 이미 지워졌다면 `기존-해소`로 적는다.
3. 수색 시간은 기록이 다루지 않은 부분에 쓴다.

## 찾을 것
- 어디서도 import·호출·라우팅되지 않는 파일, 컴포넌트, 함수, 클래스, 메서드, 엔드포인트
- 쓰이지 않는 import, 변수, 상수, 타입, DTO, 리포지토리 메서드
- 프론트가 부르지만 백엔드에 없는 API 호출, 또는 백엔드에 있지만 아무도 부르지 않는 API
- 주석 처리된 코드 덩어리, 같은 기능을 하는 중복 파일
- 커밋되면 안 되는 파일: 빌드 산출물, `node_modules`, IDE 설정, 로그, 비밀값
- 쓰이지 않는 의존성(package.json, build.gradle, requirements*.txt)
- 코드와 맞지 않는 오래된 문서·설정

## 하지 말 것
- 결론을 단정하지 않는다. "불필요 확정"이라고 쓰지 말고 근거만 적는다.
- 스타일 개선이나 리팩터링 제안은 후보가 아니다.

## 출력 형식
후보마다 아래 형식으로 적는다. 번호는 `S-01`, `S-02` ...로 붙인다.

```
S-01 | 경로[:줄] | 종류(파일/함수/import/API/의존성/문서/커밋된산출물) | 기존/기존-해소/신규
주장: 한 문장 ("X는 어디서도 쓰이지 않는다")
근거: 실행한 검색 명령과 결과 요약
```

맨 끝에 "수색한 범위"와 "못 본 범위"를 따로 적는다.
