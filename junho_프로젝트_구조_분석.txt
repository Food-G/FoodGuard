[사용자] "AI 예측 실행" 버튼 클릭
    ↓
Predictions.tsx
    └── handleTrigger()
        ├── storeId 확인
        ├── setTriggering(true)
        └── predictionService.trigger(storeId)
                ↓
            services/predictionService.ts
                └── api.post('/predictions/{storeId}/trigger')
                    (Authorization: Bearer {JWT} 자동 추가)
                                ↓  HTTP POST


[Backend] PredictionController.java
    └── triggerPrediction()  [@PostMapping("/{storeId}/trigger")]
        ↓
    PredictionService.java
        └── triggerPrediction(storeId)
            └── restTemplate.postForObject(
                    "http://localhost:8000/api/predict/store/{storeId}"
                )
                            ↓  HTTP POST


[AI Service] routers/prediction.py
    └── trigger_store_prediction()
        ↓
    services/prediction_service.py
        └── predict_and_save_store(db, store_id)
            │
            ├── [1] data_service.get_active_menus(db, store_id)
            │       └── SELECT * FROM MENU
            │           WHERE store_id=? AND is_active=1
            │
            ├── [2] data_service.get_store_region(db, store_id)
            │       └── SELECT region FROM STORE WHERE store_id=?
            │
            ├── [3] weather_service.fetch_forecast_weather(region, api_key, days=7)
            │       ├── 기상청 단기 예보 API  (D+1, D+2)
            │       └── 기상청 중기 예보 API  (D+3 ~ D+7)
            │       반환: DataFrame[날짜, 최고기온, 최저기온, 강수량, ...]
            │
            └── [4] 메뉴별 반복:
                    predict_and_save_menu(db, store_id, menu_id, ...)
                        │
                        ├── [4-1] data_service.get_sales_data(db, store_id, menu_id)
                        │           └── SELECT sales_date, SUM(quantity)
                        │               FROM SALES_DATA
                        │               WHERE store_id=?, menu_id=?, is_deleted=0
                        │           반환: DataFrame[날짜, 판매량]
                        │
                        ├── [4-2] weather_service.fetch_historical_weather(lat, lon)
                        │           └── Open-Meteo Archive API (과거 날씨)
                        │
                        ├── [4-3] DemandPredictor.fit(sales_df, weather_df)
                        │           └── ml/demand_predictor.py
                        │               ├── 데이터 수에 따라 전략 선택
                        │               │   ├── 30개 이상 → FULL_FEATURE (14개)
                        │               │   └── 7~30개   → MINIMAL_FEATURE (8개)
                        │               ├── feature_engineering.build_features()
                        │               │   ├── add_date_features()
                        │               │   │   (요일, 월, 주말, 휴일 여부)
                        │               │   ├── add_lag_features()
                        │               │   │   (lag_1, lag_7, lag_14)
                        │               │   └── add_rolling_features()
                        │               │       (rolling_mean_7, rolling_mean_14)
                        │               ├── 날씨 피처 병합
                        │               │   (최고기온, 최저기온, 강수량,
                        │               │    is_rainy, is_hot, is_cold)
                        │               └── RandomForestRegressor 학습
                        │                   (n_estimators=200, max_depth=8)
                        │
                        ├── [4-4] DemandPredictor.predict(days=7, forecast_df)
                        │           └── 7일 반복:
                        │               ├── make_future_feature_row()  ← 미래 피처
                        │               ├── model.predict(X)           ← 예측값
                        │               └── _calc_confidence()
                        │                   ├── base = R² × 85%
                        │                   ├── 예측값이 ±2σ 이내면 +10%
                        │                   └── 예측일 멀수록 -1.5%/일
                        │                   (최소 15%, 최대 95%)
                        │
                        └── [4-5] data_service.save_predictions_bulk()
                                    ├── DELETE FROM PREDICTION_RESULT
                                    │   WHERE target_date >= CURDATE()
                                    └── INSERT INTO PREDICTION_RESULT
                                        (store_id, menu_id, target_date,
                                         predicted_qty, confidence,
                                         model_version="rf_weather_v1.0")


    ↑ 응답 반환 (menus_predicted, status)

  ├── role: OWNER / HQ_ADMIN / DELIVERY_DRIVER
  └── createdAt

  STORE  (USER 1:N)
  ├── id, storeName, region, address, phone
  ├── openedAt
  └── user_id (FK → USER)

  MENU  (STORE 1:N)
  ├── id, menuName, category, price
  ├── imageUrl, is_active
  └── store_id (FK → STORE)

  MENU_INGREDIENT  (MENU N:M INGREDIENT)
  ├── id, quantity
  ├── menu_id (FK → MENU)
  └── ingredient_id (FK → INGREDIENT)

  INGREDIENT
  ├── id, ingredientName, unit, standardQuantity
  └── (메뉴 구성 식재료)

  SALES_DATA  (STORE, MENU N:N)
  ├── id, saleDate, quantity
  ├── is_deleted  ← Soft Delete 사용
  ├── store_id (FK), menu_id (FK)
  └── createdAt

  PREDICTION_RESULT  (SALES_DATA 기반 생성)
  ├── id, target_date, predicted_qty
  ├── confidence, model_version
  ├── store_id (FK), menu_id (FK)
  └── createdAt

  INVENTORY
  ├── id, quantity, lastUpdated

  ORDER_REQUEST
  ├── id, status, requestDate
  └── store_id (FK)

  NOTIFICATION
  ├── id, message, isRead, createdAt
  └── user_id (FK)

[ 4. 예측 모델 전략 ]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  데이터 수     모델 전략                 피처 수   신뢰도
  ────────────────────────────────────────────────────────────────
  7개 미만      예측 불가                  -        0%
  7 ~ 29개     RandomForest MINIMAL       8개      최대 40%
  30개 이상     RandomForest FULL+날씨    14개     최대 95%

  신뢰도 계산:
    기본값   = R² 점수 × 85%
    보정값   = 예측값이 과거 평균 ±2σ 이내면 +10%
    감소값   = 예측일이 멀수록 하루당 -1.5%
    최소/최대 = 15% ~ 95%
