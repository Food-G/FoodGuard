ML 모델 — demand_predictor.py (Random Forest)
데이터 수전략피처 수신뢰도
< 7개예측 불가 (0 반환)—0%
7 ~ 29개Random Forest + 최소 피처 (요일 평균 보조)8개40%~31% (decay)
≥ 30개Random Forest + 날씨 피처 포함 전체18+6=24개R²×85% (최대 95%)
※ 신뢰도: 예측일이 멀수록 하루당 1.5% 감소 (최소 15%). 예측값이 평균 ±2σ 내면 +10%

발표 시 강조할 내용
🤖
AI 예측 자동 발주
RandomForest 모델이 판매이력+날씨 데이터로 7일 수요 예측 → 식자재 필요량 자동 계산 → 발주 추천. 3개 테이블을 교차 조회하는 핵심 비즈니스 로직.
🚚
실시간 WebSocket 배송 추적
배송기사 GPS → STOMP WebSocket → Spring Boot 브로드캐스트 → 점주 앱 Leaflet 지도에 실시간 트럭 위치 표시.
👥
역할 기반 완전 분리
OWNER(가맹점주)와 HQ_ADMIN(본사)가 동일한 앱에서 전혀 다른 화면과 기능을 사용. JWT role 값으로 라우팅·메뉴·API 접근 모두 분기.

FoodGuard는 판매 데이터를 AI가 학습해 수요를 예측하고,
예측 결과로 식자재를 자동 발주하며,
실시간 GPS로 배송을 추적하는 통합 재고관리 플랫폼입니다.
