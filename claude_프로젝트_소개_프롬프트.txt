────────────────────────────────────────────────────────────────────────────────
■ 프로젝트 개요
────────────────────────────────────────────────────────────────────────────────

프로젝트명: FoodGuard
목적: 식당/프랜차이즈 매장의 음식 수요를 AI로 예측하여 식재료 낭비를 줄이고
      탄소 절감에 기여하는 시스템
GitHub: https://github.com/Food-G/Test-Repository

주요 기능:
- 메뉴별 7일치 판매량 AI 예측 (RandomForest + 날씨 데이터)
- 판매 기록 입력 및 통계
- 재고 관리 및 발주 요청
- POS 시스템 연동
- 배송 기사 위치 추적 (WebSocket)
- 역할 기반 접근 제어 (점주 / 본사 관리자 / 배송기사)

────────────────────────────────────────────────────────────────────────────────
■ 기술 스택
────────────────────────────────────────────────────────────────────────────────

Frontend:
  - React 18 + TypeScript
  - Material-UI (MUI) v5
  - ECharts (차트 시각화)
  - Fetch API 기반 커스텀 HTTP 클라이언트
  - 실행 포트: localhost:5173

Backend:
  - Spring Boot 3.x + Java 17
  - Spring Data JPA + Hibernate
  - Spring Security + JWT (HS256) 인증
  - WebSocket (STOMP) - 실시간 알림/위치 추적
  - Gradle 빌드
  - 실행 포트: localhost:8080

AI Service:
  - FastAPI (Python 3.11)
  - scikit-learn (RandomForestRegressor)
  - pandas, numpy
  - joblib (모델 저장/로드)
  - SQLAlchemy (DB 접근)
  - 날씨 API: Open-Meteo (과거), 기상청 공공API (예보)
  - 실행 포트: localhost:8000

Database:
  - MySQL (TiDB Cloud 호환)
  - Spring Boot → JPA로 접근
  - AI Service → 순수 SQL (SQLAlchemy)로 직접 접근

────────────────────────────────────────────────────────────────────────────────
■ 핵심 기능 흐름 - AI 예측 실행
────────────────────────────────────────────────────────────────────────────────

1. 사용자가 Predictions.tsx에서 "AI 예측 실행" 버튼 클릭
2. predictionService.trigger(storeId) → POST /api/predictions/{storeId}/trigger
3. Backend PredictionController → PredictionService.triggerPrediction()
4. RestTemplate으로 AI Service 호출 → POST http://localhost:8000/api/predict/store/{storeId}
5. AI Service에서:
   a. DB에서 활성 메뉴 목록 조회
   b. 매장 지역 정보 조회
   c. 기상청 API로 7일 예보 데이터 수집
   d. 메뉴별 반복:
      - DB에서 과거 판매 데이터 조회
      - Open-Meteo에서 과거 날씨 데이터 조회
      - RandomForest 모델 학습 (날짜/시계열/날씨 피처)
      - 7일치 수요 예측 + 신뢰도 계산
      - DB(PREDICTION_RESULT 테이블)에 결과 저장
6. Frontend에서 예측 결과 재조회 후 차트/테이블로 시각화

────────────────────────────────────────────────────────────────────────────────
■ DB 주요 테이블
────────────────────────────────────────────────────────────────────────────────

USER            : 사용자 (OWNER / HQ_ADMIN / DELIVERY_DRIVER)
STORE           : 매장 (USER 소속)
MENU            : 메뉴 (STORE 소속, is_active 플래그)
SALES_DATA      : 판매 기록 (is_deleted로 Soft Delete)
PREDICTION_RESULT : AI 예측 결과 (target_date, predicted_qty, confidence)
INVENTORY       : 재고
ORDER_REQUEST   : 발주 요청
NOTIFICATION    : 알림
INGREDIENT      : 식재료
MENU_INGREDIENT : 메뉴-식재료 관계 (N:M)

────────────────────────────────────────────────────────────────────────────────
■ AI 예측 모델 상세
────────────────────────────────────────────────────────────────────────────────

모델: RandomForestRegressor (scikit-learn)
  - n_estimators=200, max_depth=8, min_samples_leaf=2

데이터 수에 따른 전략:
  - 7개 미만   : 예측 불가 (0%)
  - 7~29개    : MINIMAL_FEATURE (8개 피처)
  - 30개 이상  : FULL_FEATURE (14개 피처) + 날씨 데이터

생성 피처:
  - 날짜: day_of_week, month, is_weekend, is_holiday 등
  - 시계열: lag_1, lag_7, lag_14, rolling_mean_7, rolling_mean_14
  - 날씨: temp_max, temp_min, precipitation, is_rainy, is_hot, is_cold

신뢰도 계산:
  - 기본값 = R² 점수 × 85%
  - 예측값이 과거 평균 ±2σ 이내면 +10%
  - 예측일 멀수록 하루당 -1.5% 감소
  - 최소 15%, 최대 95%

모델 저장: joblib → trained_models/store_{id}_menu_{id}.joblib

■ 주요 API 엔드포인트
────────────────────────────────────────────────────────────────────────────────

Backend (Spring Boot :8080):
  POST /api/auth/login                       로그인
  POST /api/auth/signup                      회원가입
  POST /api/predictions/{storeId}/trigger    AI 예측 실행
  GET  /api/predictions/{storeId}            예측 결과 조회
  GET  /api/predictions/{storeId}/summary    예측 요약
  POST /api/sales                            판매 등록
  GET  /api/sales/{storeId}/range            기간별 판매 조회
  GET  /api/menus/{storeId}                  메뉴 조회
  GET  /api/stores                           매장 목록

AI Service (FastAPI :8000):
  POST /api/predict/store/{store_id}                   전체 메뉴 예측
  POST /api/predict/store/{store_id}/menu/{menu_id}    특정 메뉴 예측
  GET  /api/predict/store/{store_id}                   저장된 예측 조회
  POST /api/train/store/{store_id}                     모델 재학습

────────────────────────────────────────────────────────────────────────────────
■ 인증 방식
────────────────────────────────────────────────────────────────────────────────

- 로그인 시 서버에서 JWT(HS256) 토큰 발급
- 클라이언트는 localStorage에 저장
- 모든 API 요청 헤더에 Authorization: Bearer {token} 포함
- Backend JwtFilter에서 매 요청마다 토큰 검증
- JWT payload에 email, role, userId 포함
